# First Presidency and Quorum of the Twelve Talks

This folder is a focused subset of the full General Conference archive. It contains talks from speakers whose calling identifies them as part of the First Presidency or the Quorum of the Twelve Apostles at the time of the talk.

Included callings:

- President of the Church.
- First Counselor, Second Counselor, or Counselor in the First Presidency.
- Member, President, or Acting President of the Quorum of the Twelve Apostles.

Excluded callings:

- Secretary or administrative callings that mention the First Presidency.
- Other General Authorities, auxiliary leaders, and invited speakers who are not in the First Presidency or Quorum of the Twelve for that talk.

## Files

`first_presidency_and_twelve_all.md`

The complete subset in one file. This is useful for full-text search, analysis, import into tools, or reading everything in one continuous document.

`first_presidency_twelve_part1.md`, `first_presidency_twelve_part2.md`, etc.

The same subset split into smaller files of about 200 talks each. These are easier for editors, GitHub, Obsidian, and other tools that can struggle with very large markdown files.

## Order

The files are oldest-first.

`first_presidency_twelve_part1.md` starts with the oldest talks, and the highest-numbered part contains the newest talks. Future conference updates are added to the latest part until a new part is needed.
